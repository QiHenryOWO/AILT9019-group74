Information Navigator

Ask a question in plain English and get a short answer with the official HKU page it came from — or a clear refusal and the right helpline when the question is medical, legal or an emergency.

Why this exists

HKU student services are published, but not where a student's question lands.

Scattered by office, not by question

Visa, housing, money, health, IT and deadlines each live on a different site with its own vocabulary. "Can I get a loan?" belongs to no office name a first-year would guess.

Timing makes errors expensive

A missed fee deadline or a wrong visa step is not repaired by rereading a page later. Students ask friends, or ask nobody, close to the deadline.

Some questions must not be answered

Chest pain, suicidal thoughts or a landlord dispute should not get a chatbot's improvised advice. Those turns go straight to a human contact.

How it works

Four stages, and one of them is a deliberate dead end.

  1. Guard

    Rule-based check for medical, mental-health, legal and emergency questions. Word boundaries keep "medical library" safe.

  2. Retrieve

    BM25 over 30 curated pages, written in this repository. The page title is scored as its own field; the top three pages become context.

  3. Generate

    A grounded prompt limits the model to the retrieved text and requires a source line. If the pages do not answer it, the model must say so.

  4. Cite

    Sources are attached from the retrieved documents, not from the model's text, so a citation cannot be invented.

Example session · rebuilt from a real run How do I book a group study room at the library?
You can book a study or discussion room through the HKU Libraries Booking a Space or Study Room page. The page lists bookable spaces such as Main Library AV group viewing rooms and Tin Ka Ping Education Library discussion rooms, and links to the booking form.

One failure we can explain. "Emergency loan" retrieves the Overseas Emergency Assistance page instead of Financial Assistance: "emergency" repeats across the crisis page, and lexical matching cannot tell a financial product from a crisis. We report it rather than hide it, because a confident answer pointing at the wrong office is the worst failure this system can produce.

Safety boundary

The system is built to stop, not to improvise.

It does not give medical, mental-health, legal or emergency advice

When a question falls in those four categories, retrieval and the language model are skipped entirely. The student receives fixed official contacts instead:

  • Emergency: 999
  • University Health Service · CEDARS counselling
  • SENDA (equal opportunities) · 2389 2222

Skipping the model is a design decision: no generation means no chance to invent triage.

Limitations we would fix next

  • English only. Tokenisation is English; a Chinese question will usually retrieve nothing.
  • Missing pages. Several CEDARS pages and the Registry site are JavaScript-rendered or unreachable, so housing, student-card and transcript questions honestly return "I do not have that information".
  • Lexical, not semantic. Synonyms ("loan" vs "financial assistance") break matching; embeddings or query expansion would help.
  • Curated subset. 30 pages cover eight services, not every HKU office, and pages age.

Run it yourself

Fresh clone, no API key needed for the retrieval check.

git clone https://github.com/QiHenryOWO/AILT9019-group74
cd AILT9019-group74
python -m pip install -r requirements.txt
cp .env.example .env          # add the group key for generation
python ingest.py              # Index built: 30 docs
python evaluate.py --no-llm   # retrieval only
python evaluate.py            # 15 questions, uses API credits
streamlit run ui.py
